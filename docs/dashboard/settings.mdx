## Companion

| Setting | Notes |
|---|---|
| Bridge port | Where the companion listens on localhost. Change it when you run the companion with `--port`; the Overview setup snippets follow. Default `9223`. |
| Connection | Live status with the connection age, or the last error, plus **Connect** / **Disconnect**. |

## Other clients

Shows the [HTTP endpoint](/connect/http-endpoint) with a copy button:

```text
http://127.0.0.1:9223/mcp
```

## Developer browser

Whether the agent may launch separate Chrome, Brave, Firefox or Zen sessions. **Only when needed** (default), **Always**, or **Never**. When several dashboards are connected, the most restrictive setting applies. See [Tool policy](/concepts/tool-policy#developer-browser-policy).

## Connection graph

On by default. Shows [Graph](/dashboard/graph) in the sidebar with the agents and browsers connected to the companion. Turning it off hides the page and stops graph updates for this profile. It does not disconnect agents or change tab sharing. The setting is saved independently in each browser profile.

## Browser behavior

**Work in background — Do not switch away from my active tab** is on by default and saved per browser profile. Agent-created tabs open in the background; input and screenshots target the assigned tab without activating it. Explicit agent activation and window resizing are blocked while enabled. Opening the dashboard or selecting a tab yourself still works.

If a page needs foreground interaction, select the agent tab yourself or temporarily turn this setting off. With it off, the previous foreground behavior is available. Check the page before retrying an action.

## Agent overlay

**Show the agent at work** switch, on by default. Draws the soft cyan halo, moving cursor and Stop button on this profile's tabs while the agent drives them. See [The agent overlay](/concepts/tabs-and-sharing#the-agent-overlay).

The overlay is available in Chromium and Firefox. On Firefox extension tabs the in-page Stop button is unavailable; use the dashboard's sharing and Stop controls instead.

## Privacy

**Activity log** switch. Off by default; see [Activity](/dashboard/activity).

## Emergency stop

Stops access to this profile's tabs, clears its shared list, switches Share everything off and disconnects this extension. Other connected profiles and developer sessions remain available. **Resume** reconnects this profile; share tabs again afterwards. To close developer sessions, ask the agent to use `browser_session` with `action: "close"` and the context name, or `all: true`.

## Appearance

The sidebar's theme control switches between system, light and dark. The choice is stored per browser profile. Every page has full light and dark palettes; screenshots in these docs show both.
